# BeltLine Pace Run Club

A five-page interactive React + Vite website built as an optional coded companion to the ColorStack Tech League Design Derby **Figma** submission.

## Run in VS Code

1. Open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL printed by Vite.

## Important: competition submission

The official rules require a native Figma file with a cover, design system, at least four desktop frames (we target five), clickable prototype, Decision Log, and AI Use Log. This code is **not** a substitute for the Figma file. Recreate/reference the 1440px pages in Figma and confirm with organizers if a live coded demo is allowed as a supplement.
